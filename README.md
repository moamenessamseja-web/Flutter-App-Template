# Flutter App Template

Template repository for new Flutter/Android apps. Everything else (CI, agent rules, skills) lives in
[Flutter-Android-Build](https://github.com/moamenessamseja-web/Flutter-Android-Build).

Create a new app from it: use the green "Use this template" button, or `POST /repos/moamenessamseja-web/Flutter-App-Template/generate`.
Then give an agent the idea. See `AGENTS.md`.
